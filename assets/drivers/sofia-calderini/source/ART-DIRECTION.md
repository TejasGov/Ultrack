# Sofia Calderini driver intro artwork

Original fictional Swiss-Italian driver, 27, beside the red Ferrari 488 Pista at a Lugano-inspired paddock. Chess knight in hand references her calm, strategic personality. Artwork generated with the built-in imagegen tool as one wide cel-shaded illustration; it contains no generated lettering or logos. The composition uses inked outlines, graphic shadows, warm late-day light, and clear left-side space for the title layout.

The final composition uses Saetta's Racing Sans One font, colors, logo and Ray-Ban sponsor art from the project assets. The Ferrari badge is the existing local maker mark. Source artwork is `illustration-v1.png`; web artwork is compressed as `illustration-v1.webp`.
