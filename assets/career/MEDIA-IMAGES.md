# Press photos: provenance

Art for the career's Media tab (`track-viewer/src/game/career/media.js`). Web files: `track-viewer/public/assets/drivers/<slug>/media/<mood>.webp`, made by `track-viewer/scripts/make-driver-media.mjs` from the raw downloads in `sources/driver-media/<slug>/<mood>.png`. The look of each driver is defined in `assets/teams/CHARACTERS.md`.

Source for everything below: ChatGPT image generation in the user's ChatGPT Plus account, driven through the Claude desktop app's built-in browser. All characters are fictional; prompts name no real person, team, car maker or sponsor.

Every first prompt in a driver's chat opens with the style lock from `CHARACTERS.md`. Later images in that chat say "same character, same face, same suit, same style as the previous image".

From Valois on, every image is landscape 3:2, and each win prompt adds "keep the whole head and trophy well inside the frame". Layla Qasimi's win came with two candidates to compare; the second was kept as the closer match to the prompt.

Dejected shots (`down`) were made in the driver's own chat, so they follow that driver's earlier images. The pair scenes (`drivers/pairs/<id>.webp`) were made in new chats from written descriptions alone, and were checked by eye against the portraits.
